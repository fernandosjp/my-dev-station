# My Dev Station for macOS

Uses cross-platform tools to set up a dev station for macOS. Inspired by [Omakub by DHH](https://github.com/basecamp/omakub) and adapted to my tools.

Desktop Application include:
- Chrome
- VS Code
- Spotify
- Slack
- more..

Terminal applications include:
- claude-code
- gemini-cli
- btop
- alacritty
- more..

## Installation

```
wget -O - https://raw.githubusercontent.com/fernandosjp/my-dev-station/refs/heads/main/boot.sh | sh
```

## Testing

```
sh dev-mode.sh
```
